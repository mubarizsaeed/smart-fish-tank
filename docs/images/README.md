To regenerate the architecture diagram after editing it:

```bash
python3 docs/make_architecture.py
```

To retake the 3D still (headless Chrome, any OS):

```bash
chrome --headless=new --window-size=1800,1125 --hide-scrollbars \
  --screenshot=docs/images/esp32-node-3d.png "file:///$PWD/docs/esp32_node_3d.html?static=1"
```
